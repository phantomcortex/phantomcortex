# phantomcortex

Linux tinkerer who builds his own OS, drags Windows tools into the Linux daylight,
and themes GNOME until it stops looking like GNOME.

- 🖥️ Maintaining **[DistinctionOS](https://github.com/phantomcortex/DistinctionOS)** —
  Bazzite with my own unholy modifications welded on top. Immutable, Cosign-signed,
  rebuilt every few days.
- 🗡️ Bringing the Skyrim modding workflow to *native* Linux — archives, meshes,
  textures, and audio, handled by GNOME itself. No Wine, no apologies.
- 🎨 A wardrobe of GTK/GNOME themes, and the occasional local-AI experiment.

### 🧩 Teaching the Linux desktop to speak Bethesda
Patches & plugins that let stock GNOME apps handle game files natively — shipped in DistinctionOS:

- **[gstreamer-plugin-xwm](https://github.com/phantomcortex/gstreamer-plugin-xwm)** —
  plays Microsoft xWMA (`.xwm`) game audio in any GStreamer app.
- **[glycin](https://github.com/phantomcortex/glycin)** — DDS/BC7 texture decoding,
  so game textures thumbnail right in the file manager.
- **[file-roller](https://github.com/phantomcortex/file-roller)** — BSA/BA2 read
  *and write* support, inside GNOME's own archive manager.
- **[Rust-BSA-BA2-Handler](https://github.com/phantomcortex/Rust-BSA-BA2-Handler)** —
  the Rust engine that packs & unpacks Bethesda archives (GUI + CLI) behind that integration.
- **[nifskope](https://github.com/phantomcortex/io.github.phantomcortex.nifskope)** —
  NifSkope, Flatpak-packaged with Steam auto-detection.

Mostly I mess around with personal projects and _occasionally_ contribute upstream.
